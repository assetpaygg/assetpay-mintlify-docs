---
title: "Verification Status"
description: "Return the client's current verification level, associated email address, latest Signicat process, and the linked verified identity if one already exists."
---

Returns the authenticated client's current verification level, associated email, latest Signicat process, and linked verified identity (if any).

**Authentication:** Client Token (`Authorization` header)

## Request

```http
GET https://api.assetpay.gg/client/verification/status
Authorization: CLIENT_TOKEN
```

## Response

```json
{
  "requestId": "...",
  "success": true,
  "data": {
    "verificationLevel": 1,
    "email": "user@example.com",
    "latestProcess": {
      "dossierId": "dossier-uuid",
      "processId": "process-uuid",
      "captureUrl": "https://capture.signicat.com/...",
      "status": "ACCEPTED",
      "createdAt": "2026-03-04T14:30:00Z",
      "completedAt": "2026-03-04T14:35:00Z"
    },
    "linkedIdentity": {
      "id": "identity-uuid",
      "firstName": "John",
      "lastName": "Doe",
      "documentCountry": "NOR",
      "linkedAt": "2026-03-04T14:35:00Z"
    }
  }
}
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `verificationLevel` | number | `0` = none, `1` = PictureID-verified |
| `email` | string \| null | Email set during `/start`, used for linking |
| `latestProcess` | object \| null | The `ACCEPTED` process if the client has one among its recent processes, otherwise the most recent process. Null if never started |
| `linkedIdentity` | object \| null | Linked verified identity, or null if not yet verified |

A client AssetPay has never seen returns `verificationLevel: 0` with `email`, `latestProcess` and `linkedIdentity` all `null`.

### Process Statuses

| Status | Meaning |
|--------|---------|
| `CREATED` | Process created, capture URL generated, no result yet. An abandoned process stays `CREATED` |
| `ACCEPTED` | Verification successful: `verificationLevel` is now 1 |
| `REJECTED` | Document or selfie failed validation, or the identity is banned |
| `ERROR` | Something went wrong during processing |

## Rate Limits

30 requests per minute.

## Errors

| Code | Key | When |
|------|-----|------|
| 1005 | `RATE_LIMITED` | More than 30 requests in a minute (HTTP 429) |
| 1102 | `INVALID_TOKEN` | Client token is invalid or expired |
| 1108 | `MISSING_BEARER` | The `Authorization` header is missing |

---
title: "Get Trade History"
description: "Return the authenticated client's trade history with cursor-based pagination, filterable by trade type and game, for reconciliation and support tooling."
---

Returns the trade history for the authenticated client. Supports filtering by type and game with cursor-based pagination.

Only trades created through the client flow for this Steam account under your merchant account are returned. Trades you create yourself through the `/secure/*` endpoints are not included.

**Authentication:** Client Token (`Authorization` header)

## Request

```http
GET https://api.assetpay.gg/client/trades?type=deposit&game=730&limit=20
Authorization: CLIENT_TOKEN
```

### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `type` | string | - | Filter by `"deposit"` or `"withdraw"` |
| `game` | string | `730` | Game app ID (`"730"` = CS2, `"252490"` = Rust) |
| `cursor` | string | - | Opaque cursor from a previous response's `nextCursor`. Omit on the first page. A cursor that can't be decoded is ignored and the first page is returned. |
| `limit` | number | `20` | Trades per page (min 1, max 100) |

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `items` | [Trade](/reference/types#trade)[] | Array of trade objects, newest first |
| `nextCursor` | string \| null | Opaque cursor for the next page. Pass it back in the `cursor` query parameter. `null` when there are no more results. |

Depending on the trade, each object can also carry `externalClientUserId`, `offerID`, `revertedBy`, `botInfo`, `error`, `activeAt` and `autoCancelAt`. Deposit items include the Steam `assetId` of the deposited item.

### Paginating

```typescript
let cursor: string | null = null;
do {
  const url = new URL('https://api.assetpay.gg/client/trades');
  url.searchParams.set('type', 'deposit');
  if (cursor) url.searchParams.set('cursor', cursor);
  const res = await fetch(url, { headers: { Authorization: CLIENT_TOKEN } });
  const { data } = await res.json();
  for (const trade of data.items) {
    // process trade
  }
  cursor = data.nextCursor;
} while (cursor);
```

## Rate Limits

| Merchant Status | Limit |
|----------------|-------|
| Verified | 3,000 requests / min |
| Unverified | 30 requests / min |

## Errors

| Code | Key | When |
|------|-----|------|
| 1001 | `VALIDATION_FAILED` | Invalid query parameter (HTTP 400, details in `error.fields`) |
| 1005 | `RATE_LIMITED` | Rate limit exceeded (HTTP 429) |
| 1007 | `SYSTEM_MAINTENANCE` | Service is in maintenance mode (HTTP 503) |
| 1102 | `INVALID_TOKEN` | Client token is invalid or expired |
| 1108 | `MISSING_BEARER` | No `Authorization` header |

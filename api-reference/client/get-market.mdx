title: "Get Market Items"
description: "Return the items currently available to buy for withdrawal, with search, filtering, sorting and pagination. Authenticated with a client token; CS2 and Rust."
---

Returns items currently available on the market for purchase (withdrawal). Supports search, filtering, sorting, and pagination.

**Authentication:** Client Token (`Authorization` header)

## Request

```http
GET https://api.assetpay.gg/client/market?game=730&search=awp&sort=priceAsc&page=1&perPage=50
Authorization: CLIENT_TOKEN
```

### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `game` | integer | `730` | `730` (CS2) or `252490` (Rust). Any other positive integer is served as CS2. |
| `search` | string | - | Search by item name (max 100 chars) |
| `sort` | string | - | `relevance`, `priceAsc`, `priceDesc`, `nameAsc`, or `nameDesc` |
| `minPrice` | number | - | Minimum price filter (USD, `0` or more) |
| `maxPrice` | number | - | Maximum price filter (USD, `0` or more) |
| `page` | number | `1` | Page number |
| `perPage` | number | `50` | Items per page (1 to 1000, or `-1` to return every matching item) |
| `development` | boolean | `false` | Sandbox flag (`true`/`false` or `1`/`0`). When on, CS2 supplier listings are limited to instant delivery, and every returned item is stamped with instant delivery, a placeholder `previewToken`, a synthetic holding `botInfo` and a synthetic `assetId`, so you can build against the full item shape using cheap live listings. An item with no offer gets `{ "price": 0, "delivery": "instant" }`. |

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `items` | [Item](/reference/types#item)[] | Available market items |
| `count` | number | Total matching items (for pagination) |

### Key Item Fields for Withdrawals

| Field | Description |
|-------|-------------|
| `id` | Pass back as `itemId` in the withdrawal request |
| `itemId` | The parent catalog item, not the listing. Pass it to [`GET /client/market/item`](/api-reference/client/get-item-listings) to see every listing of the same item. CS2 only. Never pass this as the withdrawal `itemId`; that is the `id` above. |
| `offer.price` | Purchase cost in USD. Pass this back as `items[].price` in the withdrawal request. |
| `offer.delivery` | `"standard"` (bot sources from supplier and sends a Steam trade offer) or `"instant"` (item already pre-positioned on the bot). CS2 only: Rust rows don't carry it outside sandbox mode. |
| `marketPrice` | On CS2 supplier listings, equal to `offer.price`. Pool rows (those carrying `botInfo`) and Rust rows omit it. |
| `assetId`, `classId`, `instanceId`, `botInfo` | Present on pool rows: the Steam asset and the bot already holding it. These rows always deliver `"instant"`. |

## Rate Limits

| Merchant Status | Limit |
|----------------|-------|
| Verified | 300 requests / min |
| Unverified | 30 requests / min |

## Errors

| Code | Key | When |
|------|-----|------|
| 1001 | `VALIDATION_FAILED` | Invalid query parameter (HTTP 400, details in `error.fields`) |
| 1005 | `RATE_LIMITED` | Rate limit exceeded (HTTP 429) |
| 1007 | `SYSTEM_MAINTENANCE` | Service is in maintenance mode (HTTP 503) |
| 1102 | `INVALID_TOKEN` | Client token is invalid or expired |
| 1108 | `MISSING_BEARER` | No `Authorization` header |

---
title: "Get Item Listings (Self-Trade)"
description: "Merchant-side listing lookup for one item type; pass the returned listing id straight to the secure buy endpoint. Authenticated with a merchant API key."
---

Merchant-facing equivalent of [`GET /client/market/item`](/api-reference/client/get-item-listings). Returns the available listings for a specific item type. Pass the listing `id` to [`POST /secure/buy`](/api-reference/secure/buy).

**Authentication:** Merchant API Key (`api-key` header)
**Scope:** `CORE_ACCESS`

## Request

```http
GET https://api.assetpay.gg/secure/market/item?itemId=0cabcab6d22d2281&delivery=any&page=1&perPage=50
api-key: ap_...
```

### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `itemId` | string | Required\* | Item type ID (from `/secure/market` or `/secure/prices`), 1–256 chars. Provide this **or** `marketHashName`; `itemId` wins when both are sent. |
| `marketHashName` | string | Required\* | Exact market hash name (e.g. `AK-47 \| Redline (Field-Tested)`), 1–256 chars, resolved to the catalog item id. CS2 only. Ignored when `itemId` is supplied. |
| `delivery` | string | `any` | `"any"`, `"standard"` (trade-offer), or `"instant"` |
| `phase` | string | - | Doppler phase: `"Phase 1"`–`"Phase 4"`, `"Ruby"`, `"Sapphire"`, `"Black Pearl"`, `"Emerald"`. Returns only that phase's listings. Combinable with `delivery`. |
| `floatMin` | number | - | Lower bound on the item float/wear value (`0`–`1`). |
| `floatMax` | number | - | Upper bound on the item float/wear value (`0`–`1`). |
| `page` | number | `1` | Page number |
| `perPage` | number | `50` | Listings per page (max `100`) |

\* Provide either `itemId` or `marketHashName`.

## Response

Same shape as [`GET /client/market/item`](/api-reference/client/get-item-listings#response). Each listing carries `offer.price`, `offer.delivery`, and any sticker/charm/float details. Listings never include `itemId`, since you named the item in the request.

```json
{
  "requestId": "...",
  "success": true,
  "data": [
    {
      "id": "listing-uuid-1",
      "marketHashName": "AK-47 | Redline (Field-Tested)",
      "marketPrice": 10.50,
      "offer": {
        "price": 10.50,
        "delivery": "standard"
      },
      "wear": "0.15234",
      "paintSeed": 123
    }
  ]
}
```

<Note>
The `delivery` filter is applied by the marketplace when listings are fetched, not afterwards. `standard` also leaves out AssetPay pool units, which always deliver instantly.
</Note>

## Rate Limits

| Merchant Status | Limit |
|----------------|-------|
| Verified | 6,000 requests / min |
| Unverified | 100 requests / min |

## Errors

| Code | Key | When |
|------|-----|------|
| 14 | `LISTING_NOT_FOUND` | The item's marketplace listings could not be loaded and AssetPay has no pool stock of it. HTTP 404 |
| 1001 | `VALIDATION_FAILED` | Neither `itemId` nor `marketHashName` was sent, or a parameter is out of range. HTTP 400, see `error.fields` |
